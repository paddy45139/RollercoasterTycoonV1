# Tiny Park Tycoon

A small theme park management game built with **Phaser 4.2.1** (vendored in `lib/`, MIT) and vanilla JavaScript.

## Run locally
No build step. Serve the folder with any static server:

```
python3 -m http.server 8080
```

Then open http://localhost:8080.

## How to play
Pick a tool in the left menu, hover over the map (a green outline means you can build there, red means you can't), and click to build. You can drag to lay paths or bulldoze several tiles. Bulldozing refunds 50% of the price.
